# 企业微信会议室助手

在项目根目录打开 PowerShell，使用 Conda 的 `py313` 环境安装依赖并启动会议室 API。

```powershell
conda activate py313
python -m pip install -r wecom/requirements.txt
python -m uvicorn api.main:app --host 127.0.0.1 --port 8000
```

在另一个已激活 `py313` 的 PowerShell 窗口，从同一目录启动机器人。

```powershell
python -X utf8 -m wecom.main
```

机器人读取项目根目录 `.env` 中的 `WECOM_BOT_ID` 和 `WECOM_BOT_SECRET`。终端显示「企业微信已认证」后，保持该窗口运行。

1. 单聊「会议室助手」，发送 `你好`。预期收到「连接成功」和指令提示。
2. 发送 `我的账号`，复制回复中的企业微信 UserID。
3. 在第三个已激活 `py313` 的 PowerShell 窗口执行下面的绑定命令。这里以样例人物 `P000001` 为例，也可以换成你要使用的人员编号。

```powershell
python -X utf8 -m wecom.main --bind P000001 "替换成刚收到的UserID"
```

4. 回到单聊发送 `查我的预约`。机器人按发送者的绑定身份查询，显示本人创建、主持或参加的前 5 条预约。

预约查询使用现有 FastAPI，默认地址为 `http://127.0.0.1:8000`。使用独立 SQLite 文件时，在 API、机器人和绑定命令所在的三个窗口设置相同的 `MEETING_DB_PATH`。

## 群聊

在企业内部群打开「添加成员 → 智能机器人」，添加现有的「会议室助手」。在群输入框输入 `@` 并从名单选择机器人，然后发送指令。

- `@会议室助手 你好` 验证群聊收发。
- `@会议室助手 查空闲会议室 明天 14:00-15:00 8人` 查询指定时段能容纳 8 人的会议室。
- `@会议室助手 查空闲会议室 2026-12-01 09:00-10:30` 按指定日期查询。日期可以用「今天」「明天」或 `YYYY-MM-DD`，时段使用北京时间和 24 小时制，人数可省略。

群成员可以直接查空闲会议室。「我的账号」和「查我的预约」会提示到单聊办理。若企业微信里的机器人名称与「会议室助手」不同，可在 `.env` 设置 `WECOM_BOT_NAME` 为实际显示名称。

如果第一条查询忘了 @，在群里引用那条文本，再选择 `@会议室助手` 并发送「查一下」。也可以复制原查询，与 @ 放在同一条消息里。

可以先发「@会议室助手 查空闲会议室 明天」，等机器人询问后，再发「@会议室助手 14:00-15:00 8人」。每次补充都需要 @，并由同一人在同一群发送。等待补充的查询在 5 分钟无操作后过期，重启机器人也会清除。
